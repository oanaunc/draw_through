# Website privacy policy update for the learning revision

The existing public policy at https://oanarinaldi.com/drawthroughprivacy.html returned HTTP 200 on 16 October 2026. It describes reference images and compositions. The app now links to it from Settings. This file prepares the additional wording for the website owner; it has not been published to that website.

Add to the local-storage section:

> Lesson drawings, written reflections, lesson bookmarks, completion records, and the dates of saved studies are stored in the app's private storage on your device. We do not receive this information. The app keeps one revisitable drawing per lesson. Clearing a lesson drawing removes its saved marks; the reflection and completion record remain. Uninstalling the app removes its local data, subject to device backups you manage through Apple.

Add to the sharing section:

> You can export a copy of a lesson drawing using Apple's system share sheet. The drawing is shared only with the destination you choose. The app does not automatically publish lesson drawings or reflections.

The app adds no analytics, advertising, accounts, or backend service in this revision. Update the public policy's product description to include illustrated lessons and an in-app practice pad, and its effective date when that website change is actually published.
