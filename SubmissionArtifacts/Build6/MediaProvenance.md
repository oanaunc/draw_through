# Final store media

Ten screenshots each for iPhone 6.9-inch and iPad 13-inch. `Raw` contains genuine simulator captures, with real local studies and selected generated test photos. Promotional headings are outside the actual app capture. The AppKit renderer is `scripts/render_store_screenshots.swift`. No controls or app content were synthesized.

Captures use build 5, except iPad Studio board and adjustments captured after the build-6 hit-area correction. Course, features and appearance match build 6. The reviewer walkthrough was recorded on build 5 and accelerated 4×; the final build adds the manually tested Studio interaction fix. It is an attachment for App Review, not an App Preview.

Overview contact sheets are for review convenience and are not uploaded as screenshots.
